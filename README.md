# АМ Авто

Сайт автосервиса с PHP/MySQL API и React-админкой. На сервере нужен обычный Apache-хостинг с PHP и MySQL — Node.js, MongoDB, SSH и постоянно работающий процесс не нужны.

## Что нужно

- PHP 8.0+ с расширениями `PDO` и `pdo_mysql`
- MySQL 5.7+ или MariaDB
- Apache с поддержкой `.htaccess` и `mod_rewrite`
- Node.js/npm только на компьютере, где собирается архив для загрузки

## Собрать архив для хостинга

В Windows из корня проекта выполните:

```powershell
npm run build:hosting
```

Скрипт соберёт сайт и админку и создаст `hosting-package.zip`. Ключ для создания первого администратора скрипт напечатает в консоль — сохраните его до окончания настройки.

## Развернуть

1. В панели хостинга создайте MySQL-базу и пользователя с полными правами на эту базу.
2. Загрузите `hosting-package.zip` в корневую папку сайта (обычно `public_html`) и распакуйте его.
3. Импортируйте `database.sql` из распакованного архива в свою базу через phpMyAdmin.
4. В файловом менеджере хостинга откройте `api/config.php` и укажите имя базы, пользователя и пароль. Не меняйте автоматически созданные `jwt_secret` и `setup_key`.
5. Откройте `https://ваш-домен/install.php`, вставьте ключ из консоли и создайте администратора с уникальным паролем от 12 символов.
6. Удалите `install.php` через файловый менеджер хостинга.
7. Сайт работает на основном домене, админка — по адресу `https://ваш-домен/admin/`.

Все заявки и настройки хранятся в вашей MySQL-базе. Вложения не загружаются на сервер: фотографии для галереи добавляются ссылками, как и раньше.

## Локальная разработка админки

```powershell
cd admin
npm install
npm start
```
