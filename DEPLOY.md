# Установка на обычный PHP-хостинг

Приложение размещается как набор обычных файлов. На хостинге не устанавливаются npm-пакеты, не запускаются фоновые процессы и не настраивается Railway.

## Перед загрузкой

1. Проверьте в панели хостинга наличие PHP 8.0+, расширений PDO и `pdo_mysql`, MySQL/MariaDB и Apache `.htaccess`/`mod_rewrite`.
2. На своём компьютере установите Node.js, откройте PowerShell в корне проекта и выполните:

   ```powershell
   npm run build:hosting
   ```

3. Сохраните ключ установки, показанный в консоли. Он сгенерирован только для этого архива.

Команда создаёт `hosting-package.zip` со статическим сайтом, PHP API, админкой, SQL-схемой и конфигурацией. Пересборка создаёт новые ключи — при повторной сборке используйте ключ именно от нового архива.

## База данных и файлы

1. В панели хостинга создайте базу данных MySQL и отдельного пользователя. Выдайте этому пользователю все права только на эту базу.
2. Загрузите `hosting-package.zip` в папку сайта, чаще всего `public_html`, и распакуйте его там. Файл `.htaccess` должен находиться непосредственно в корне сайта.
3. Импортируйте `database.sql` в созданную базу с помощью phpMyAdmin. Таблицы создаются пустыми.
4. Через файловый менеджер хостинга откройте `api/config.php` и укажите `host`, `name`, `user` и `password`. Хост обычно `localhost`, но используйте значение из панели хостинга. Не меняйте ключи `jwt_secret` и `setup_key`.
5. Проверьте, что панель хостинга не переименовала и не удалила скрытый `.htaccess`.

## Первый вход

1. Откройте `https://ваш-домен/install.php`.
2. Введите ключ установки из консоли, имя администратора, email и надёжный пароль длиной от 12 символов.
3. После подтверждения удалите `install.php` через файловый менеджер хостинга.
4. Войдите в админку: `https://ваш-домен/admin/`.

Если при открытии `/api/...` появляется 404, попросите поддержку хостинга включить Apache `mod_rewrite` и разрешить директивы `.htaccess`. Если установщик не подключается к базе, проверьте значения в `api/config.php`, наличие импортированных таблиц и расширения PHP `pdo_mysql`.

## Обновление сайта

Измените исходники, снова выполните `npm run build:hosting` и загрузите новые файлы из архива поверх старых. Не перезаписывайте `api/config.php` на уже работающем сайте: там находятся пароль к базе и ключ подписи токенов. Не загружайте повторно `install.php`; если файл появился, удалите его.

## Данные и безопасность

- База при первом развёртывании пустая. Данные из MongoDB/Railway не импортируются.
- Не публикуйте `api/config.php` и не помещайте его в общедоступный GitHub.
- `.htaccess` блокирует прямой доступ к конфигурации и SQL-файлу; не удаляйте его.
- Используйте HTTPS и уникальный пароль администратора.
- Делайте резервные копии MySQL из панели хостинга.
- Регистрация пользователей через API отключена; первичный аккаунт создаёт одноразовый установщик.
